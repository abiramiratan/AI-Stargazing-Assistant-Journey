# Mini Project 02 — LST & Planet Hour Angle Calculator
This project calculates the Hour Angle (HA) of a selected planet using real-time astronomical data from the Skyfield library.

The Hour Angle is one of the most important concepts in observational astronomy because it tells us where an object is located relative to the observer's local meridian.

Using the observer's longitude and the current time, this project:

* Computes the current Greenwich Mean Sidereal Time (GMST)
* Converts GMST into Local Sidereal Time (LST)
* Retrieves the planet's Right Ascension (RA) and Declination (Dec)
* Calculates the Hour Angle (HA)
* Determines whether the planet is:
    * Rising (East of Meridian)
    * Crossing the Meridian
    * Setting (West of Meridian)
