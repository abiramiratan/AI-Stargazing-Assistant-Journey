# AI Stargazing Assistant Journey

This repository documents my journey of building an AI-powered Stargazing Assistant from first principles.

Instead of relying entirely on astronomy libraries, I am learning and implementing the mathematics behind celestial coordinate systems, Earth rotation, visibility calculations, and observational astronomy. The goal is not only to build an application, but also to understand the science and mathematics that make it possible.

## Project Vision

My long-term goal is to develop a web application that recommends the best celestial objects to observe based on:

* Astronomical visibility calculations
* Weather conditions
* User location
* Machine learning recommendations

The application is designed for astronomy enthusiasts, beginners, students, and curious skywatchers who want to explore the night sky more effectively.

Rather than asking users to search through hundreds of celestial objects, the system will identify and recommend the most suitable objects to observe on a given night at a specific location.

## Why Build This When Stellarium Already Exists?

Applications such as Stellarium and Sky Walk provide excellent visualizations of the night sky and help users identify objects through interactive sky maps and augmented reality.

This project focuses on a different problem:

**"What should I observe tonight?"**

Instead of simply showing everything visible in the sky, the AI Stargazing Assistant aims to recommend the best observable celestial objects based on:

* Location and GPS coordinates
* Visibility calculations
* Weather conditions
* Observation quality
* User interests and experience level

The objective is to reduce the time users spend searching and help them discover the most rewarding observations available at that moment.

## Learning Philosophy

This repository is intentionally structured as a learning journey rather than a single final project.

Each module focuses on understanding the underlying concepts, mathematics, and implementation details before integrating them into the final application.

The goal is to document not only the finished product, but also the process of learning astronomy, machine learning, and software engineering along the way.
